# Shodlik Education — Editorial Curriculum Pass v6

## Purpose
This pass moves the course from structural authoring toward teacher-reviewed quality. The focus is natural lexical usage, useful collocations, and exercise validity.

## Changes
- Replaced the advanced-course generic word example `We need to discuss [word] in context.` with domain-aware contextual examples.
- Replaced artificial collocations such as `key [word]` and `[word] policy` with curated domain collocations.
- Improved advanced exercise prompts so question-form, transformation, and error-correction tasks refer to the actual lesson topic/sentence.
- Added an editorial audit script that checks for known placeholder/template patterns and duplicate literal IDs.
- Preserved the existing CEFR structure and all 54 advanced lessons.

## Pedagogical rule
A vocabulary item should be taught through:
1. meaning,
2. pronunciation,
3. natural collocation,
4. contextual example,
5. controlled retrieval,
6. communicative use.

A grammar item should be taught through:
1. meaning/use,
2. form,
3. contrast,
4. model examples,
5. controlled practice,
6. communicative production.

## Remaining editorial work
The course is not declared textbook-complete until each lesson has passed human-style review for CEFR fit, naturalness, translation accuracy, listening authenticity, exercise answer validity, and progression from the previous lesson.

## Item metadata
- CEFR level
- difficulty 1–5
- skill
- item type
- cognitive demand
- grammar/error focus
- discrimination tag
- related lesson

## Selection policy
1. Weak skill target first when evidence exists.
2. Difficulty is matched to the learner's observed mastery.
3. The selector prefers skill and exercise-type diversity.
4. Review/diagnostic items can exclude recently used IDs.
5. A lesson test remains bounded by the authored lesson item pool.

## Pedagogical note
Difficulty 1–5 is an instructional calibration, not a psychometric parameter. True item discrimination requires response data from a sufficiently large learner sample. The app therefore does not claim statistical item difficulty until enough real response data exists.
